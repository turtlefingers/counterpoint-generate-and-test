# Procedural Counterpoint

이 프로젝트는 1957년 레자렌 힐러(Lejaren Hiller)와 레너드 아이작슨(Leonard Isaacson)이 일리악 슈트(Iliac Suite)에서 사용한 '생성 후 테스트(Generate-and-Test)' 패러다임을 웹 기술로 구현한 대위법 프로그램입니다. 난수 생성 알고리즘과 음악적 제약 규칙을 결합하여 2성부 대위법 선율을 생성합니다.

## 시스템 아키텍처 및 주요 기능

### 1. 알고리즘 기반 작곡 엔진
컴퓨터가 난수를 발생시켜 후보 음표를 생성하면, 사전에 정의된 대위법 필터 프로그램이 해당 음표가 음악적 규칙을 준수하는지 즉시 검증합니다. 모든 규칙을 충족한 음표만 악보에 고정되며, 규칙 위반 시 다른 후보 음표를 생성하는 과정을 반복합니다.

### 2. 동적 리듬 생성 시스템
고전적인 1종 대위법의 온음표 고정 방식을 넘어, 매 음표 생성 시마다 가중치 기반 확률 모델을 사용하여 리듬을 결정합니다.
- **리듬 가중치**: 4분음표(40%), 8분음표(25%), 2분음표(25%), 온음표(10%)
- 가용한 마디별 박자(4/4박자) 내에서 남은 시간에 따라 선택 가능한 음표 리듬을 실시간으로 계산하여 적용합니다.

### 3. 실시간 규칙 검증 시각화
UI의 규칙 리스트를 통해 현재 검증 중인 음표가 어떤 규칙을 통과하거나 위반했는지 시각적으로 표시합니다. 특히 병행 3/6도의 경우 현재 연속 발생 횟수를 실시간으로 카운팅하여 사용자에게 정보를 제공합니다.

### 4. 악보 및 오디오 엔진
- **VexFlow**: SVG 기반 음악 기호 및 악보 렌더링합니다. 리듬 다양화 모드 활성화 시 가독성을 위해 8마디를 2개의 시스템(4마디씩 2줄)으로 자동 분할 배치합니다.
- **Tone.js**: 생성된 선율을 폴리포닉 신디사이저로 출력하며, 재생 시 현재 연주 중인 음표를 악보상에서 하이라이트 표시합니다.

## 적용된 대위법 규칙 상세

1. **음역 확인 (Range)**: 고음부(Treble)와 저음부(Bass) 각각 지정된 음역 범위를 벗어나지 않도록 제한합니다.
2. **도약 제한 (Leap)**: 인접한 두 음 사이의 간격이 9반음(장6도)을 초과하는 급격한 도약을 방지합니다.
3. **수직적 협화음 (Consonance)**: 두 성부 간의 음정 관계가 완전/불완전 협화음(1, 3, 4, 7, 8, 9, 12, 15, 16반음 간격)인지 확인합니다.
4. **병행 진행 금지 (Parallel)**: 성부 간의 독립성을 위해 동일한 완전 협화음(1도, 5도, 8도)으로의 병행 진행을 금지합니다.
5. **3/6도 연속 제한 (Repetition)**: 병행 3도 또는 6도의 진행이 3회를 초과하여 발생하지 않도록 제한합니다.
6. **시작과 종료 (Start/End)**: 악곡의 첫 마디와 마지막 마디는 반드시 완전 협화음(1도 또는 8도)을 구성해야 합니다.

## 기술 스택

- **Vite**: 프로젝트 빌드 및 개발 환경 관리
- **VexFlow**: SVG 기반 음악 기호 및 악보 렌더링
- **Tone.js**: Web Audio API 기반 오디오 합성 및 재생 제어
- **Vanilla JavaScript**: 핵심 엔진 로직 및 UI 인터랙션 구현

## 설치 및 실행 방법

1. **의존성 설치**
   ```bash
   npm install
   ```

2. **개발 모드 실행**
   ```bash
   npm run dev
   ```

3. **프로덕션 빌드**
   ```bash
   npm run build
   ```
